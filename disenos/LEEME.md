# Diseños de referencia

Cada archivo `.dc.html` es una pantalla del canvas de diseño. Son HTML con estilos inline: léelos para copiar estructura, espacios, colores y textos.

No se abren solos en el navegador, porque dependen del runtime del editor de diseño. No copies `<x-dc>`, `<sc-if>`, `{{variables}}` ni el bloque `DCLogic`: son del editor.

- Sin prefijo: versión móvil (390 × 844)
- `Web-…`: versión de escritorio (1440 de ancho, fluida)
